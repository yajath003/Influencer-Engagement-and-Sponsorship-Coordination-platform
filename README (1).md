# INFLUENCER ENGAGEMENT AND SPONSORSHIP COORDINATION PLATFORM - IESCP

The IESCP project is a platform designed to facilitate interaction between Influencers and Sponsors. Influencers help publish ad requests sent by Sponsors for their mutual benefit. The platform has three main roles:

**Influencer:**  Influencers are users who are recognized as celebrities by the public. They accept or request sponsorships to publish ads in exchange for rewards.

**Sponsors:** Sponsors are representatives of a company who create campaigns with a set budget and design ads for their products. They request Influencers to publish these ads on their platforms.

**Admin:** The Admin oversees all activities on the platform, monitoring processes to ensure compliance. They have the authority to flag or unflag users who appear suspicious.

The project is divided into three modules:

• **Admin**    
• **Influencers**  
• **Sponsors**  
Each module is further structured into three Python files:  
• **Forms:** Contains form input validations.  
• **Views:** Manages routes and logic for the pages.  
• **Models:** Defines the database tables and relationships.

## Run Locally

Clone the project

```bash
  git clone https://github.com/yajath003/Influencer-Engagement-and-Sponsorship-Coordination-platform.git
```

Go to the project directory

```bash
  cd Influencer-Engagement-and-Sponsorship-Coordination-platform
```

Install dependencies

```bash
  pip install -r requirements.txt
```

Start the Server

```bash
  python main.py
```
